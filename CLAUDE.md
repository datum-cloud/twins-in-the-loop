# Twins in the Loop

Astro 7 + Tailwind 4 editorial site. Package manager is Bun.

## Commands

- `bun run dev`
- `bun run test`
- `bun run lint`
- `bun run check`
- `bun run build`

## Conventions

Follow `.cursor/rules/` even when working in Claude Code:

- MDX for all page and post copy
- Component-first UI in `src/components/`
- Reusable helpers in `src/lib/` (not Astro frontmatter)
- Conventional Commits and Release Please for versioning
- No Turborepo
